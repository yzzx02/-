# PeakTruthLab 项目说明（筹备版）

## 项目目标
PeakTruthLab 面向 **LC-MS 非靶向峰识别与定量**，目标是形成可投稿分析化学期刊的算法论文与开源代码：
- 在复杂背景下稳定区分真峰 / 假峰。
- 提升峰边界定位与积分准确性。
- 提供可解释结果，降低“黑箱”质疑。
- 与 XCMS、MS-DIAL、Asari 建立统一基准对比。

## 当前阶段
目前为**准备阶段**，优先完成：
1. 数据与标注规范；
2. 模型路线验证（分类 / 检测 / 分割）；
3. 自动化基准测试框架；
4. 论文核心图表模板。

## 技术路线（建议）

### 1) 数据表示与输入管线
- 直接读取 `.mzML`（优先 pyOpenMS），避免截图式转图。
- 从原始 profile/centroid 构建 ROI 张量，建议保存：
  - 时间维（RT）
  - 质荷比维（m/z）
  - 强度（intensity）
- 支持保留时间漂移增强（RT shift augmentation）与噪声注入。

### 2) 模型架构候选
- **分类基线**：1D-CNN / ResNet 风格主干（真峰 vs 假峰）。
- **全局上下文模型**：CNN + Transformer（或 BiLSTM）混合架构。
- **检测模型**：输出峰起止边界（start/end）并做唯一匹配。
- **分割模型**：U-Net 风格点级分类，处理重叠峰与拖尾峰。

### 3) 损失函数与训练策略
- 类别不平衡：Focal Loss。
- 边界回归：L1 + IoU/CIoU 组合损失。
- 训练记录：完整保存 loss、F1、PR-AUC、检出率、误检率。

### 4) 可解释性模块（新增重点）
新增方向：**深度学习真假峰 + 可解释性**。
- 模型输出不仅给出真假标签，还输出解释特征：
  - 峰形平滑度
  - 峰宽
  - 对称性/拖尾因子
  - 信噪比（SNR）
  - 局部基线波动
- 提供两层解释：
  1. **后验可视化**（Grad-CAM / Attention map）
  2. **特征归因报告**（例如 SHAP/重要性分解）
