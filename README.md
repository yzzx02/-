# 鞘脂保留时间拟合工具

本项目用于对脂质质谱数据（鞘脂等）进行分类、碳数/不饱和度提取及保留时间拟合，并自动生成拟合曲线图表。

---

## 如何在 VSCode 中拉取本仓库代码

### 第一次克隆（首次下载）

1. 打开 VSCode，按 **Ctrl+Shift+P**（Mac：**Cmd+Shift+P**）打开命令面板。
2. 输入 `Git: Clone`，按回车。
3. 在弹出的输入框中粘贴仓库地址：
   ```
   https://github.com/yzzx02/-
   ```
4. 选择本地保存文件夹，点击"确定"后 VSCode 会自动克隆并提示打开。

> 也可以在终端（Terminal）中运行：
> ```bash
> git clone https://github.com/yzzx02/-
> cd -
> code .
> ```

---

### 已有本地仓库时拉取最新代码

1. 在 VSCode 中打开已克隆的项目文件夹。
2. 点击左侧活动栏中的 **源代码管理** 图标（或按 **Ctrl+Shift+G**）。
3. 点击 **…**（更多操作）按钮 → 选择 **拉取（Pull）**。

> 或者在 VSCode 内置终端（**Ctrl+`**）中运行：

> git pull
> ```

## 使用方法

```bash
python main.py
```

运行后按提示输入 Excel 文件路径（如 `RT结果.xlsx`），程序将自动：

1. 对脂质注释进行分类
2. 提取总碳数与不饱和度
3. 对每个分类的每个不饱和度组合生成独立图表（保存在 `拟合结果/` 目录）
4. 生成各分类的总览拟合图
5. 将拟合结果汇总保存为 Excel

### 输出文件说明

| 文件 | 说明 |
|------|------|
| `拟合结果/*_single.png` | 每个(类别, 不饱和度)组合的独立图，标题如 `CAEP(d14:4:X:0)` |
| `拟合结果/*_all.png` | 某类别下所有不饱和度的总览图（含半透明原始点） |
| `拟合结果/*_all_clean.png` | 某类别下所有不饱和度的总览图（仅拟合成功的点） |
| `拟合结果/拟合结果汇总.xlsx` | 各类别各不饱和度的拟合方程与 R² 汇总 |
